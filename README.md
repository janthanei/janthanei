# Jan Thanei

My work sits mainly at the intersection of Python services, web applications, document workflows, and external integrations. I care about making AI useful inside real processes, including the validation, permissions, failure handling, and human review needed around the model.

## Selected work

### [Invoice Bot](https://github.com/janthanei/ebner-transport-bots)

A production automation that monitors an Outlook mailbox, extracts invoice-related documents and links, suppresses duplicates, and submits validated PDFs for printing. Built with Python, Microsoft Graph, Playwright, PrintNode, pytest, and systemd. It currently processes approximately 2,000 documents per month.

### [AI Message Router](https://github.com/janthanei/wskz-exercise)

A local-LLM application that classifies incoming requests and routes them through a constrained email tool. Built with FastAPI, LangChain, Ollama, Docker Compose, and MailHog, with application-side validation that limits the actions available to the model.

### [Private Document Signing with Aztec](https://github.com/janthanei/aztec-signing-next)

My bachelor's thesis project: a full-stack prototype for privacy-preserving document signing using the Aztec protocol. The repository contains the web application, backend, and Noir smart-contract setup.

### [Watten.live](https://watten.live)

A production-deployed multiplayer browser game with authentication, real-time gameplay, rankings, payments, and backend APIs. Built with Next.js, React, TypeScript, Node.js/Express, PostgreSQL/Prisma, Supabase Auth, Stripe, and Docker.
