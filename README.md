# Jan Thanei

Software engineer based in Poznan. I build web apps, integrations and automation, mainly with Python, TypeScript and React.

My projects range from removing repetitive office work to getting a card game online. Some solve an everyday problem; others give me a reason to explore something new.

## Selected projects

- **[Invoice Bot](https://github.com/janthanei/ebner-transport-bots)** - Collects invoice documents from Outlook and handles printing, without someone opening each email by hand.
- **[Watten.live](https://watten.live)** - A multiplayer browser version of the card game Watten, with live games and rankings.
- **[AI Message Router](https://github.com/janthanei/wskz-exercise)** - An experiment using a local language model to sort incoming messages and route them to the right department.
- **[Private document signing](https://github.com/janthanei/aztec-signing-next)** - My bachelor's thesis prototype exploring privacy-preserving document signing with Aztec.
